## 💻 Featured Projects & Systems

* 🛡️ **Sentinel Fraud Detection Engine:** Engineered a financial risk assessment architecture utilizing highly imbalanced data and deployed it seamlessly on AWS.
* 🔥 **AI-Powered Autonomous Fire Suppression System:** Final-year project utilizing edge inference on an ESP32-S3 microcontroller coupled with focused acoustic arrays for rapid, autonomous fire mitigation.
* 🌲 **Algerian Forest Fire Predictor:** Designed an environmental risk modeling full-stack application utilizing Ridge Regression algorithms to forecast fire outbreaks.
* 🏥 **Smart Patient Triage System:** Developed an ML-driven application designed to prioritize patients dynamically based on symptom severity, packaged and deployed via Streamlit.
* 📊 **Cloud-Based BI Integrations:** Created comprehensive dashboards leveraging Snowflake, BigQuery, AWS, and Azure for deep loan, product, and housing data analysis.
* ⚙️ **Exploratory Data Analysis Engine:** Engineered features and applied advanced visualizations on datasets including Play Store metrics, Red Wine quality, and Flight Prices using Python and Pandas.
